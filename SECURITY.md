# Política de seguridad

## Comunicación responsable de vulnerabilidades

Si detectas una posible vulnerabilidad en la web de 4iSEG, comunícala de forma privada a **info@4iseg.com**.

Incluye, cuando sea posible:

- La URL o el componente afectado.
- Una descripción clara del problema.
- Los pasos necesarios para reproducirlo.
- El impacto potencial.
- Capturas o pruebas que no contengan datos sensibles.

No publiques la vulnerabilidad en una incidencia de GitHub ni la divulgues antes de que haya podido revisarse y corregirse.

## Alcance

Esta política cubre la versión publicada de [4iseg.com](https://4iseg.com) y los archivos de este repositorio. Los servicios de terceros enlazados desde la web quedan fuera de alcance.

## Investigación responsable

Evita acciones que puedan afectar a la disponibilidad del sitio, acceder a datos ajenos, degradar servicios o realizar ingeniería social. Utiliza únicamente pruebas mínimas y no destructivas.

4iSEG revisará los avisos recibidos y responderá en función de su gravedad y de la información disponible. Actualmente no existe un programa de recompensas económicas por vulnerabilidades.
