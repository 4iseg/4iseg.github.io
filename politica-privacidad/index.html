// POLÍTICA DE PRIVACIDAD/

Privacidad en 4iSEG

Última actualización: 7 de octubre de 2026.

Responsable y contacto

El responsable de este sitio web es 4iSEG. Para cualquier consulta relacionada con privacidad o protección de datos puedes escribir a info@4iseg.com.

Datos tratados

Esta web es informativa y no contiene formularios de registro ni solicita datos personales. Si contactas voluntariamente por correo electrónico, utilizaremos los datos incluidos en tu mensaje únicamente para atender la consulta y mantener las comunicaciones necesarias.

Test de hábitos digitales

Las respuestas y el resultado del test se procesan localmente en tu navegador. No se envían a 4iSEG ni se almacenan en una base de datos.

Infraestructura y registros técnicos

El sitio se publica mediante GitHub Pages y se distribuye a través de Cloudflare. Estos proveedores pueden tratar datos técnicos necesarios para prestar, proteger y diagnosticar el servicio, como la dirección IP, la fecha y hora de acceso, el recurso solicitado y datos básicos del navegador.

Recursos externos

La web puede solicitar la tipografía JetBrains Mono a Google Fonts. Al cargarla, el navegador se conecta con servidores de Google y puede comunicar datos técnicos como la dirección IP.

Cookies y almacenamiento local

4iSEG no utiliza cookies propias ni guarda las respuestas del test en el almacenamiento local del navegador. Los proveedores de infraestructura pueden emplear mecanismos estrictamente necesarios para la seguridad y prestación del servicio.

Conservación y derechos

Los mensajes recibidos por correo se conservarán durante el tiempo necesario para atender la consulta y cumplir las obligaciones legales aplicables. Puedes solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad escribiendo a info@4iseg.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.

Cambios

Esta política podrá actualizarse cuando cambien la web, sus proveedores o las obligaciones aplicables.
